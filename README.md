## 版本管理｜SEMVER-20261023-01

三套 Skill 从2026-10-23起严格采用 **V主.次.修**；当前均为 **V1.1.0**。

- **主版本**：仅核心逻辑或框架推倒重来才考虑；当前严禁升级，保持主版本1。
- **次版本**：周五汇总考核后，有新增已验证有效技巧入库或重大规则更新时递增，修订号归零；没有合格变化不升版。
- **修订号**：日常错别字、描述、待改进清单等微调递增。仅有实际修改的 Skill 升级；三套共改则一起升级。
- 所有新 commit、PR及合并 commit 的标题必须带目标版本，例如 `【V1.1.1】补充分镜底线要素`。仅归档、回执、信用记账等未改执行内容的提交沿用所关联的当前版本，不空升版本。
- 当前版本以 `main` 的各包 `version.json` 为准，与 `SKILL.md`、本表和 `registry/latest.json` 同步。历史标签、历史标题和原验证事实保留；治理修订编号不能代替版本号。
- 保留具体发布内容确认、候选三票及目标媒介验证门槛。本次三套统一发布 V1.1.0 已获用户明确指令，不再重复征求同批发布许可；任何技巧的未验证状态不因整包升版自动改变。

周五先完成巩固、去重、证据审计和相应回测；有合格技巧入库或重大规则更新，并获对应发布确认后，升级次版本。日常微调升级修订号。无实质变化不机械升版。

每次先固定并核验备份，再创建带版本号的 PR、检查实际差异、按授权合并并独立回读 main。GitHub 为唯一发布来源，旧云端停用。保存步骤见[GitHub保存与PR发布规则](skills/script-video-shot-director/references/dual-save-policy.md)。
