# 工作流

保存可以迁移到不同软件的制作思路、阶段案例、失败与修正记录。这里记录的是“如何组织输入、生成、检查和承接”，软件按钮与接口单独存放。

本区于2026-11-17按用户要求建立。当前为项目进行中的阶段备份，完整项目总结待项目结束后补充；不把局部流程认可写成全片验收或新技巧已转正。现有三套Skill仍是创作入口。

## 怎样继续补充

- 同一问题保存“现象→证据→已确认原因／推测→处理→复检结果→剩余限制”，保留失败；只写“已解决”无法帮助下次排错。
- 通用方法写在方法页；某个软件的名称、按钮、格式、限制写在适配页。更换软件时重新检查能力，不改写历史操作事实。
- 项目具体时长、画幅、风格、音色策略、报价与额度是项目参数，不直接变成所有项目的固定要求。
- 局部认可、实际生成成功、连续性检查和完整音画终审分别记录。方法记录不自动变成active技巧，也不自动登记信用奖励。
- 后续有新证据时追加日期与修正说明；不抹掉原失败和当时未解决的问题。完整剧本、账户信息及私有媒体不随阶段方法摘要上传。

本区没有新增自动运行、付费生成或历史预算复用权限。
