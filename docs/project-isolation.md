# 制作项目隔离

每个制作项目使用唯一标识，例如 `project-a`、`project-b`。独立会话只加载该项目资料和所需共享 Skill。共享的是制作规则，不共享已确认的角色、画风、资产、剧情、台词和进度。

实际项目开始后，可在 `projects/<项目标识>/` 下保存项目说明、已确认设定、资产索引、提示词、制作结果及进度。当前没有真实项目，不建立虚假项目内容。

每次制作结果记录所用 Skill 的周版本、修订、内容摘要，以及此次确认的项目状态。Skill 更新不会重置项目资料，不批量重新制作已有作品。长任务可继续固定旧修订；出现新版时告知用户，待用户决定当前任务是否切换，下一制作请求重新核对。

学习资料和通用测试结果可另行归档。测试材料标注“合成测试”，不得当作真实规则、项目素材或已完成作品。
