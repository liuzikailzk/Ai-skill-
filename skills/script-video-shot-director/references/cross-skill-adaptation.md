# 影视：本次整合与逐镜检查

来源：现有SKILL.md导演式镜头要求、style-preproduction-policy.md、direction-and-action.md，以及用户认可的2026-10-16复盘和两项局部实践。
本文件是执行检查；不把四项缺陷写成已解决，不宣称新生成效果。

1. 生成参考图前说明故事值得看的地方、观众感受变化，以及支撑它的行为。逐镜列：镜号/起止秒数→信息任务→注意力起终点→可见情绪变化→视觉手段→切镜理由。已有画面能够回答时不机械增加镜头。
2. 按信息重要度安排时间，检查物品发现、关键动作、反应与结尾停留。不能照搬本例4×6秒，也不能用“克制”掩盖情绪不足。
3. 先核对摄影机、站位、视线、距离、出入口与物品归属，再核参考图及文字一致性；每次独立输入获得必要约束。技术参数核验独立于导演表达。
4. 开场视觉重点、焦点/视线引导、关键细节/反应覆盖、结尾铺垫四项必须写具体镜号、秒数和画面依据；无特写/反打时说明有效替代，禁止只勾“已落实”。正式清单见 improvements/2026-10-16.md。
5. 接稳再松手、跨镜一致性仅按 verified-practices/2026-10-16-returned-watch.md 的本次局部范围复用。第2镜机位反转与跨镜身份基本一致可以同时成立。
6. 光影材质沿用已确认项目卡，静态资产先锁外观与结构；漫画素材先由漫画Skill确认原作。导演方法不覆盖漫画对白或把写实戏默认改成动画打击。
7. 每周一次视频机会的本项考核，提交前完成文字和静态时序预审，实际结果为本周最终成果；不得重生成替换成绩。这是本项考核限制，不扩成所有项目的永久生成次数限制。本周测试/复盘仍暂停。
