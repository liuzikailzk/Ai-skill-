# 静态资产：光影、构图与关键细节适配

来源：本包production-baseline.md与style-preproduction-policy.md；参考影视《还好没走远》的关键物品可读性、空间连续和情绪铺垫复盘。
迁移状态：adapt_pending_validation；没有本次新图片实测，不把影视两项局部认可算作静态出图验证。

## 基础资产与剧情参考帧分开
基础人物只锁核心外形、服装和材质；临时表情不替代身份，不自动制作表情组。必要展示视角/静止状态按交付底线说明，不借迁移擅自增加动作或背景。
基础场景保持同一空间的布局、出入口、尺度和固定陈设对应；默认无角色、无剧情活动道具，不固定剧情昼夜、天气或情绪灯位。用中性展示照明看清结构材质。
道具保持单件、完整轮廓、尺度、材质及一个当前状态；默认不加手和人物，不在一条图词混写递出→接住→松手。
仅当用户另行要求分镜参考图/剧情首帧时，联合动态Skill确定镜号与时段，本Skill只负责该瞬间视觉：视角、构图、静态姿态、人物/物品位置、接触或未接触状态。写“静态画面，无运镜”；不将动态过程、剪辑、BGM写入静态图词，不扩大到其他未指定资产。

## 光影与材质
共享的是光源方向、主次、冷暖区域和材料差异的检查；基础资产用中性展示，剧情参考帧才沿用该镜已确认光照。全片材质语言与单场情绪照明分别记录，不把暖调/暗部/某胶片型号当所有项目默认。
检查金属反光、玻璃透明与反射、布料织纹、皮肤等是否有区分；磨损、浮尘、色散仅在项目需要时采用。不用同一种漫反射覆盖全部材料，也不声称器材词保证真实模拟。

## 构图、细节与空间
让核心资产或关键信息在展示尺寸下可辨，说明主体占比、观察方向、遮挡和清晰区域。重要道具先完整图，必要时另给局部；不让装饰、手、反光或虚化遮住识别依据，不为“电影感”牺牲可读性。
四视场景逐项核门窗、家具、固定陈设和尺度；相似画风不等于同一空间。动态用图核机位、视线与轴线；光影连续不能掩盖位置错误。
从“接稳再松手”只提取当前静态接触状态、持物手、数量和归属检查；动作时序回动态Skill，图片对也不证明交接视频有效。
情绪铺垫不能靠一张基础资产图完成；需要情绪参考帧时由动态Skill提供上下文，本Skill呈现当前可见姿态/表情，不虚构整段剧情。四项缺陷的静态对应见 improvements/2026-10-16.md。
