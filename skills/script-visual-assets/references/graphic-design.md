# 宣传展示与包装装饰资产

修订：ASSET-SCOPE-20261029-01。用户确认资产包含影视之外的宣传海报等视觉成品。本模块规定职责、交付和检查，不代表新模型技巧已实测有效。

## 范围与任务边界

- 宣传展示：宣传/活动海报、视频封面、横幅、宣传图、产品展示图。
- 包装装饰：人物卡/场景卡、边框、标题字、图标、贴纸、透明背景装饰。人物或产品本体与外层包装分别锁定；需要组合时交完整成品，不让用户自行拼装。
- 先沿用已给的主题、文案、素材、尺寸和风格，只补问会改变结果的关键缺口。无需剧本、年代设定或三类影视资产清单；不自动扩展整套品牌系统。
- 只有动态出场、视频封面动画等实际动态请求才联合影视Skill；静态设计不要求视频时长、运镜或对白。用户只要提示词时不擅自生图。

## 设计输入

确认用途、发布位置、受众与核心信息；沿用用户尺寸/比例、文案原文、品牌/人物/产品素材、二维码和风格要求。印刷任务再确认实际尺寸、出血、分辨率及交付格式，不将所有网络图强制套成印刷参数。

先排信息主次：主标题或核心视觉、必要说明、时间地点/价格等行动信息、Logo与二维码。按实际内容选择层级和留白，不把所有字段强塞给每张图；不用装饰遮挡主体和重要文字。

参考图写明用于身份、产品结构、构图、配色、字体气质还是材质；不继承来稿的品牌、文案、二维码或画风到其他项目。图片链接和文字名称不视为已上传参考。

## 制作与交付

1. 保留原文中的名称、日期、时间、地址、价格、联系方式和其他关键信息，不擅自补写事实。设计光影、背景、人物及文字可以是成品的一部分；基础场景“无角色”和道具“干净背景”不约束海报版式。
2. 提示词按用途/尺寸、主体或信息层级、具体布局、色彩/字体/材质、准确文案、必要素材与限制组织；写清静态平面成品，无运镜。聊天给完整可复制代码块及独立配套风格词，同份备份；修改后给完整新版，不交补丁让用户拼词。未确定信息明确为草案，不能当成最终成品。
3. 实际成品请求须交可用图片或约定设计文件。实际使用图像工具生成/编辑时遵循其能力与授权；不能把提示词当图片，不能把扁平图声称为可编辑分层源文件。若文字、Logo或二维码无法可靠呈现，应修正交付或明确尚未完成的部分，不让用户自行解决后再声称完成。
4. 真实Logo和二维码优先使用用户提供原件，避免生成近似替身。二维码只按已确认内容制作或保留，不编造链接；检查最终合成图中的解码结果是否与目标一致。未实际扫码/解码时明确“扫码功能未验证”，视觉上像二维码不能算可用。
5. 透明装饰检查真实透明通道、边缘和残留背景，棋盘格图案不等于透明。产品展示保持外形、比例、标识与关键结构，不能为了美化改变产品事实。

## 交付前检查

核对文案逐字正确、重要信息齐全、字形无乱码；检查阅读顺序、对齐、遮挡、文字对比和目标尺寸下的可读性。检查比例/像素或印刷规格是否实际满足、关键内容是否被裁切、素材身份与参考用途是否一致。二维码、透明通道及文件可编辑性按实际结果报告。

检查通过只代表对应项目已检查；没有生成、试读、扫码或用户反馈的项目标为未测，不编成功率，不把本次职责补充记作有效技巧或信用奖励。
