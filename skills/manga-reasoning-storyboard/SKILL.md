# 漫画解读与视频分镜

## 核心用途与默认执行路径（优先）

修订：MANGA-TASK-ROUTING-20261019-01。以已有漫画为剧情证据和视觉关键帧，先解读，再按请求制作动态视频分镜文字。技能加载、任务判断和制作执行分开处理：

| 当前请求 | 执行范围 |
|---|---|
| 仅启用、读取、查询或检查本Skill | 说明用途或回答检查问题，承接已有任务；没有素材或任务时只询问下一步，不编剧情、不调用生图。 |
| 理解、评价已有漫画或诊断问题 | 还原格序、对白归属、人物和事件因果，回答当前问题；不自动扩展为画漫画或正式制作。 |
| 将漫画改编为视频、要动态分镜或视频提示词 | 完成必要的漫画理解、风格确认与当前模型核验后，逐镜交时间、景别、运镜、表演动作与首帧描述；已确认创作内容沿用，模型切换按门禁重查。 |
| 明确要分镜图、首帧图或配套资产图片 | 按已授权的图片范围联动资产Skill，保留视频改编目的；正式出图前执行风格确认。 |
| 明确要原创漫画或新画漫画页 | 视为另一项明确创作任务，按该请求另定范围与输出；不把它当作加载本Skill后的默认下一步。 |

本Skill中的“分镜”默认是视频镜头规划，不是新增漫画页。“有素材”可用可执行首帧描述满足；明确要实际图片才须交图，真实候选的可视复现另按其适用规则执行。不得把素材检查、联合加载或候选评估的交图条款当作每次调用都要画图。完整交付格式见[动态视频分镜输出格式](references/output-format.md)。

已授权的制作范围由当前请求及明确的项目上下文确定，不能因读取更多Skill自行扩大。上述路由不削减本Skill自身的动态导演职责：格间动作补全、镜头调度、节奏与表演仍服务于确认后的漫画视频改编。


## 强制制作门禁：先查模型，再写提示词

修订：MODEL-CAPABILITY-GATE-20261019-01。正式视频分镜、提示词及复现试写前，必须实际读取并执行[视频模型核验与提示词适配](references/model-capability-gate.md)：确认具体画风/风格、准确宽高比与对标，主动联网核验当前模型的准确版本、实际入口、输入模式、完整能力优缺点及单次支持时长，再据此安排片段、镜头和动作。留有核对时间、来源、能力表和“结论→本次处理”，不能依赖旧记忆或只说已了解。

换模型、版本、档位、平台/入口或影响能力的输入模式，旧核验立即失效；即使换回旧模型也必须重新检索并适配。关键身份/时长/能力未查实，停止正式提示词交付，说明缺口；普通“先给一版”“照旧”和项目已有风格确认均不能替代模型核验。同目标同项目当前会话当天连续制作可沿用可回读核验卡，跨日/跨会话或出现更新、冲突及关键新需求时重查。仅启用、原作/剧本理解、诊断、版本查询或规则维护不因此自动制作或查模型。

本门禁优先于下文/旧引用中不查就试写、仅按需查能力、旧时效或“最终只保留提示词”的冲突文字；既有原作忠实、逐镜计时、风格确认和制作范围继续执行。能力未知须如实写明，不能伪造已查或实测效果。

## 制作前置：沟通、对标与风格确认

修订：STYLE-CONFIRM-BENCHMARK-20261019-01。正式制作前先读取[制作前沟通、对标与整体风格确认](references/style-preproduction-policy.md)，本节优先于旧正文中同类流程。

先理解并确认当前漫画的格序、剧情与对白归属，再只补问影响改编的关键缺口，每次一问。主动寻找并实际查看对标，分别说明原作外形依据、美术参考及动作/镜头参考；整体风格明确并经确认或按明确授权决定后，才进入正式动态改编。

已有确认沿用，只确认新缺口；仅理解、评价或诊断时不自动展开制作。完整确认流程、暂定/试写边界和本媒介适配按上述引用执行。

## 强制触发、声明与创作交付底线

治理修订：CREATIVE-DELIVERY-CASES-20261015-01；用户2026-10-15明确授权，即时执行。本节与所链接机制优先于旧默认格式和旧“仅应用户要求给时间轴”等冲突要求；版本查询也先声明实际加载证据。

- 每轮命中“分镜、镜头、景别、运镜、时间线”先加载影视分镜Skill；“漫画、分格、页面、气泡”先加载漫画分镜Skill；“角色、场景、道具、风格、资产”先加载资产Skill；“提示词、生图、生视频、解析视频”按制作对象加载对应Skill。多组命中取并集，先实际读取再回复，不假称加载。
- 回复开头逐套声明：“已加载 XX Skill。本次适用底线规则：XXX。”引用本轮实际读取的该Skill中一条具体适用规则，不能只报技能名或泛称遵守规范。完整映射与声明证据按[强制触发与交付底线](references/creative-delivery-policy.md)执行。
- 有分镜：每个镜头必须带起止秒数。复杂动作在镜内再标动作阶段时间；不承诺模型逐帧精确执行。
- 有提示词：必须带镜头描述，包含景别、运镜、主体动作。静态资产另列展示说明，运镜写“静态画面，无运镜”，主体写静止姿态或当前状态，不硬加剧情动作。
- 有素材：必须附可用的图片或首帧描述。不能把工具内部预览或仅文件路径当用户已收到图片；明确要实际图片时须实际交图。
- 多个镜头必须逐镜列出，不能合并。叙事单元可保留主编号，但各镜须独立编号/列项及起止时间。
- 任一要素确实不适用，必须逐项写：“本要素不适用，原因是：XXX。”发出前自检：“时间有没有？镜头有没有？图有没有？多个镜头是否逐镜？”缺项先补，补完再发。
